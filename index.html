DAW Project Hub

Un espacio centralizado para practicar el flujo de trabajo profesional con Git y GitHub en el desarrollo web.

Fases del Desarrollo

En la primera fase nos enfocamos en la preparación del entorno local y la vinculación segura mediante claves SSH con GitHub, asegurando un control de versiones limpio y controlado.

Posteriormente, aplicamos un flujo de trabajo basado en ramas para implementar nuevas funcionalidades y estilos, resolviendo posibles conflictos de fusión de manera integrada.

Por último, simulamos un entorno colaborativo mediante repositorios forkeados, Pull Requests e incidencias (Issues) para publicar versiones estables del proyecto.
